# Zombie Survival

Co-op zombie survival in Strasbourg. Two versions: browser (`main`: Three.js + Vite dev server with built-in WebSocket relay, deployed on Render from `main`) and Godot 4.7 port (`godot-port`, `godot/`: GDScript, solo only). Port docs: `docs/GODOT_PORT.md` (plan/log, French), `godot/README.md`.

## Rules
- Talk to the user in French. Code, commits, docs: English (existing French game text/docs stay).
- Delegate: code search -> `explorer`; new system (waves, weapons, vehicles, power-ups) -> `game-designer` first; implementation (JS or GDScript) -> `gameplay-coder`; odd behaviour/bug -> `playtest-bug-hunter`; visual/UI bug needing screenshots -> `gui-test-debugger`.
- Never commit copyrighted music (`public/music/theme.*`, `godot/assets/audio/music/theme.*` are ignored).
- Report honestly what is verified vs not. Never push without being asked; pushing `main` redeploys Render.
- Don't run two Godot processes on `godot/` at once (import cache).

## Browser (`main`)
- ES modules; balance in `src/config.js`. No test suite: check with `npx vite build` and drive the game with Playwright (`?debug`).
- Bump `package.json` version on every game change; commit subject ends `(vX.Y.Z)`.
- `docs/REFERENCE.md` and `docs/csv/` are generated by `tools/make-docs.mjs`.

## Godot port (`godot-port`)
- Own version: `config/version` in `godot/project.godot`; commit subject ends `(godot vX.Y.Z)`; leave `package.json` alone.
- NEVER rewrite `godot/project.godot` with a script (it was emptied once). Use `sed -i`, then check `wc -l` = 28 and `run/main_scene="res://scenes/main.tscn"`.
- Verify: `tools/godot-check.sh [suite]` (regenerates config and golden files from the JS, imports, runs headless tests; expect 0 failures) plus a real screenshot (real display or `xvfb-run`) for anything visual. Headless alone is not enough.
- `godot/sim/` stays pure (no nodes) and is checked against JS golden files; views live in `godot/scenes/`. If a ported JS rule changes, rerun the check.
- `godot/data/golden/j8.json` changes on each export: `git checkout` it before committing.
- Baked assets (world, textures, audio) are git-ignored; regenerate with `tools/bake-*.mjs` (see `godot/README.md`).
- Windows export: `tools/export-windows.sh`; the zip is never committed.
