# Zombie Survival

Co-op zombie survival in Strasbourg. Browser game (`main`: Three.js + Vite dev server with built-in WebSocket relay, deployed on Render from `main`).

## Core Guidelines
- **Language**: Communicate with the user in French. Write code, commit messages, and documentation in English (keep existing French game text and docs unchanged).
- **Architecture & Roles**:
  - Code search -> `explorer`
  - New system (waves, weapons, vehicles, power-ups) -> `game-designer`
  - Implementation (JS or GDScript) -> `gameplay-coder`
  - Odd behaviour or gameplay bug -> `playtest-bug-hunter`
  - Visual/UI bug requiring screenshots -> `gui-test-debugger`
- **Audio Assets**: Never commit copyrighted music (`public/music/theme.*` is git-ignored).
- **Verification**: Report honestly what has been verified vs not verified. Never push to `main` without explicit confirmation (pushing to `main` redeploys the live game on Render).

## Browser (`main`)
- Modern ES modules; all balance values in `src/config.js` (never hardcoded in logic).
- Verification: run `npx vite build` and test game scenarios using Playwright (`?debug`).
- Versioning: bump `package.json` version on every game change; commit subject ends with `(vX.Y.Z)`.
- Documentation: `docs/REFERENCE.md` and `docs/csv/` are generated by `tools/make-docs.mjs`.

### Three.js Rendering Directives (Realistic Dark Survival Aesthetic)
- **Renderer Configuration**:
  - `renderer.toneMapping = THREE.ACESFilmicToneMapping`
  - `renderer.outputColorSpace = THREE.SRGBColorSpace`
  - Soft shadows: `renderer.shadowMap.enabled = true` and `renderer.shadowMap.type = THREE.PCFSoftShadowMap`
  - Pixel ratio: `renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))`
- **Lighting & Atmosphere**:
  - Eliminate white or intense ambient light. Use very dim cold ambient (`HemisphereLight`) and faint bluish moonlight (`DirectionalLight` with `castShadow = true`).
  - Add localized `PointLight` on luminous fixtures (electric blue for Quick Revive, warm amber/yellow for street lamps and windows) with realistic range and quadratic decay (`decay: 2`).
  - Use dark exponential fog (`THREE.FogExp2`) blending the city into the night.
- **PBR Materials & Textures**:
  - Use `MeshStandardMaterial` / `MeshPhysicalMaterial` exclusively (no basic materials for world meshes).
  - Forbid pure saturated hex colors. Use desaturated, gritty survival tones with roughness between 0.6 and 0.9 and subtle metalness.
  - Configure glowing elements (monitors, neons, perk bottles, zombie eyes) with `emissive` and `emissiveIntensity` to feed the bloom halo pass.
- **Geometry & Detailing**:
  - Never leave bare sharp `BoxGeometry` cubes ("Roblox look"): add sub-mesh details (chamfers, corner brackets, frames, rims, handles, footing pads) to catch specular highlights on edges.
  - Avoid flat cardboard ground: provide normal maps, puddle variations, and roughness variations.
