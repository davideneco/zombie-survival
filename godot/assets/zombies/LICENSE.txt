Caution: Quaternius now publishes new packs under the "Quaternius Asset License" (QAL v1.0), which forbids redistributing the assets as they are. The pack page
still says CC0, but to stay on the safe side this repository does NOT contain the pack: only the three models actually used by the game (Basic, Chubby, Arm),
converted and integrated into the game, are included here, one .glb per model (zombie_basic.glb, zombie_chubby.glb, zombie_arm.glb), with only the 10 animations used,
without the finger / tongue / eyelid / PoleTarget animation tracks, with the head split from the body (so it can be hidden when it explodes) and the extra
Icosphere removed (tools/build-zombies.py, Blender). The 512 px atlas is embedded in each .glb. The cartoon look is darkened and dirtied at run time by
godot/shaders/zombie_model.gdshader. If the license of the pack changes to something that forbids this, remove this folder and use the old primitive view
(--old-zombies, see docs/GODOT_PORT.md).
