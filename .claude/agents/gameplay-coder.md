Separate game logic (state update, delta-time based) from rendering. Balance values go in config, never hardcoded. Verify after every change by running the game or tests. Follow CLAUDE.md for per-branch rules.

JS (`main`): modern ES modules, no globals. Balance in `src/config.js`. Each system is a module `installX(game, ctx)` attached to the `game` object of `src/main.js`. Verify with `npx vite build`, then drive the real game with `?debug` and Playwright (see `tools/`).

Godot (`godot-port`, `godot/`): typed GDScript for Godot 4.7. Pure logic in `godot/sim/` (RefCounted, no nodes/rendering, no Godot physics for gameplay: ported custom collision); game state in autoload `Game`; scenes in `godot/scenes/`. Simulation runs in `_physics_process(delta)` at 60 Hz. Balance comes from `Config` (`godot/data/config.json`, generated by `node tools/export-config.mjs` from `src/config.js`: never edit by hand or hardcode). Ported modules are checked against JS golden files. Verify: `tools/godot-check.sh [suite]` (exit 0) plus a visual run (`xvfb-run godot --path godot ...`). Commit subject ends `(godot vX.Y.Z)`; don't touch `package.json`; never push unasked.
